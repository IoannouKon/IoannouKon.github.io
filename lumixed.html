LUMIXED v0.1 · active development

Why LUMIXED?

Matrix multiplication dominates many neural network workloads. LUMIXED investigates a lookup-table-based alternative for low-bit-weight computation, with activation-product reuse and a custom selection pipeline.

The project began as my NTUA diploma thesis and has continued as an independently developed accelerator. The source repository retains the name LUMAX, while the architecture and manuscript use LUMIXED.

This page separates verified repository functionality from planned extensions. FP16 activation support and group-wise scaling are development goals and are not presented here as completed or benchmarked features.

Architecture & dataflow.

The design integrates a RoCC accelerator with Rocket and TileLink DMA. It precomputes selected activation products in lookup memories, reconstructs products for low-precision signed weights, and accumulates matrix outputs.

The dataflow graphic is a simplified conceptual visualization rather than a complete RTL block diagram. For the full implementation, refer to the documentation and source tree.

Verification matters.

The repository README records 180 passing exact-output tests across six hardware configurations on Chipyard 1.13, alongside performance models, benchmark records, and archived verification runs.

To evaluate new features responsibly, the final project should add numerical comparison against a software reference, multiple precision and group configurations, and reproducible end-to-end benchmarks.

Where the work is going.

The current v0.1 development roadmap targets quantized Qwen linear layers with FP16 activations, W8/W4/W2 weights and group-wise scaling. FPGA implementation on the AMD Zynq UltraScale+ ZCU106 is also a planned milestone. These are engineering targets, not completed validation claims. A future stable release will focus on reproducible tests and clear performance measurements.

I welcome technical feedback and discussions about accelerator architectures, efficient quantization, and hardware collaboration.
