Project 01 / Thesis → Independent research

LUMIXED.
Less arithmetic,
more reuse.

An experimental mixed-precision matrix multiplication accelerator built in Chisel and connected to a Rocket RISC-V core through RoCC. The central question: can careful product reuse make low-precision neural-network workloads cheaper to compute?

The idea

What if we reuse products instead of multiplying again?

Instead of using conventional multipliers for every low-bit operation, LUMIXED generates reusable activation products, stores them in local lookup memories, selects the required product using the weight, corrects odd values and sign, and accumulates the result.

It began as my NTUA diploma thesis and continues as a personal hardware research project. The GitHub repository still uses the original name LUMAX.
